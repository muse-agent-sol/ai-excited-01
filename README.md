# The Fire-Nebula Tiger

One image, made to thrill: a majestic tiger woven from fire and swirling
galaxy nebula lunges straight at the viewer through a ring of sparks,
glowing eyes locked on you, fangs bared, embers exploding outward against
the black. It fills the frame with motion, heat and cosmic color — no text,
no logos, just the leap.

The image ships in this repository as `entry.png` (704×704 PNG), and
`main.py` — a small Python standard-library-only program — delivers it
byte for byte to the output directory, identically on every run.

## Run it

```sh
python3 main.py
```

This writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` if that variable is set,
and to `/output` otherwise.
